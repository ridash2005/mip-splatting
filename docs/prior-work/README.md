# Prior work

What this project produced before the thesis. Kept because the thesis refers to
several of them, and because two record decisions that were later overturned.

| file | what it is |
|---|---|
| `EE60030-course-project-report.pdf` | The April 2026 course project, which argued that 3DGS is sharper than NeRF because it escapes the MLP's spectral bias. §8.4 of the thesis relates to it, and corrects one figure in it: its Table 3 values are 3DGS Figure 1, a single scene, and not Table 1 dataset averages. |
| `EE60030-course-project-slides.pdf` | The slides for the same. |
| `3DGS-seminar.pdf` / `.pptx` | The seminar given on 3D Gaussian Splatting, before the band-limit question was the subject. |
| `reproduction-report.pdf` | The September 2026 report on reproducing both baselines. Superseded by Chapter 7, and superseded on one point of substance: it attributed the offset from the published figures to GOF densification, which Table 7.5 later refuted. |
| `readiness-audit.pdf` | The audit that produced the C-series corrections. Its item M-2 is the over-determination between `s` and `sigma_pix` that Appendix G records as a defect. |

The reproduction report and the audit are here as the record of what was
believed at the time. Where the thesis disagrees with them, the thesis is
right and Appendix G says how the disagreement was settled.
